# 파워풀 프로야구 2026-2027 한국어 패치 v1.03

[v1.03 다운로드](https://github.com/TeamLimRyan/PAWAFURU_PRO_YAKYU_2026_2027_KOREAN_LOCALIZATION_RELEASE/releases/tag/v1.03)

영관나인 선수 정보의 엔트리 글자 깨짐과 석세스 2018 고류카쿠 고교의 장소명 뒤섞임을 수정했습니다.
홈런 모델·경기 제목 투명도 수정을 포함한 v1.02 교체본의 전체 내용을 포함합니다.

일본판 Base 1.0.0 + Update 1.1.0 전용입니다. `Pawapuro2026_KO_v1.03_xdelta.zip` 전체를 풀고
[설치 안내](INSTALL_KO.md)에 따라 수정하지 않은 원본에서 적용한 RDI·RDB·IPS를 함께 교체하세요.
이전 패치를 순서대로 적용할 필요가 없습니다. 기존 세이브는 삭제하지 마세요.
Source code ZIP은 설치 패키지가 아닙니다. Windows 자동 적용에는 Python이 필요하지 않습니다.

이번 두 수정은 ARM64 명령 검증 164건을 통과했습니다. 추가 실기 검증은 미실시이며,
2026-10-16 배포 요청에 따라 공개합니다. 투수 교체 설명의 일본어 잔존 제보는 조사 중입니다.
