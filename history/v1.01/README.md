경기 안정성·패치 로딩, 기록실·선수 명감·하이라이트 문구, 마이라이프 장비·프로필,

NSP/XCI에 직접 적용하는 패치가 아닙니다. 원본 게임·키·펌웨어·세이브는 포함하지 않습니다.
