# v1.01 — 2026-10-10

- 경기 중 메모리 부족으로 발생하던 패넌트 타임아웃 멈춤·종료를 수정하고 경기 안정성을 개선했습니다.
- 실행 코드 패치 레코드를 병합해 로딩 시 파일 읽기 횟수를 줄였습니다. 적용 결과 바이트는 유지합니다.
- 기록실 설명과 선수 명감 수상 경력에 엉뚱한 문자열이 표시되던 참조 오류를 수정했습니다.
- 선수 설명의 조사·띄어쓰기·용어와 하이라이트의 회차·초말·아웃·주자 상황 문구를 수정했습니다.
- 경기 기록의 `저장`을 야구 용어 `세이브`로 구분하고, 선수 굿즈의 일본어 `選手`를 수정했습니다.
- 기존 저장 데이터의 일본어 기본 설정 이름을 `내 설정 1~4`로 바꿉니다. 사용자가 직접 지은 이름은 유지합니다.
- 마이라이프 모델 배트·글러브·스파이크의 12개 단계 변형, 생일 말미와 금액의 만·억 단위를 수정했습니다.
- 아웃·미션 성공 이미지 및 홈런 연출 31종의 한국어 수정본을 반영했습니다.
- 사용자 전체 확인 및 1.01 배포 승인을 반영했습니다. 배포 형식은 xdelta + 필수 IPS입니다.

기준 게임 버전은 일본판 Base 1.0.0 + Update 1.1.0으로 동일합니다.
이전 패치 사용자는 정상 원본에서 다시 적용해 RDI·RDB·IPS 세 파일을 함께 교체하세요.

# v0.91 — 2026-10-03

- 같은 원본 파일로 설치해도 `만든 RES00.RDI이(가) 예상과 다릅니다. 설치에 실패했습니다.`가 뜨는 문제를 수정했습니다.
- 원인: v0.9 설치기가 PC에서 데이터를 재압축했습니다. Python 3.14의 zlib-ng와 기존 zlib가 다른 압축 바이트·배치 주소를 만들어 최종 해시가 달라졌습니다. 동일한 원본 해시로 오류를 재현했습니다.
- v0.91은 검증된 압축 데이터를 차분으로 복원하며 재압축하지 않습니다. 원본·차분·복원 본문·최종 파일의 SHA-256 검증을 유지합니다.
- 전체 데이터를 메모리에 쌓지 않고 항목별로 파일에 씁니다. 임시 폴더에서 결과를 검증한 뒤 출력에 반영하며, 일반적인 파일 교체 오류 시 기존 파일을 복구합니다.
- 실패 단계·항목·예상/실제 해시·Python 환경을 `install_report.json`에 기록합니다.
- Windows Python 3.12.10(zlib 1.3.1), 3.14.0(zlib-ng)에서 2,587개 항목 전체 설치와 출력 3파일 해시 일치를 확인했습니다. 각 환경의 오류 처리 회귀 테스트 7개도 통과했습니다.
- 게임 버전은 일본판 Base 1.0.0 + Update 1.1.0입니다. 설치 결과는 검증된 v0.9 게임 파일과 동일합니다. 이번 릴리스는 설치기 수정이며 새로운 번역·이미지 수정은 포함하지 않습니다.
