# 알려진 범위와 제한 — v1.0

- 지원 버전은 Nintendo Switch 일본판 Base 1.0.0 + Update 1.1.0입니다.
- 구장 광고·간판, 유니폼·팀 마크, 조합형 글자 그림 등 제작 의뢰자가 원본 유지로 지정한 이미지에는 일본어가 남아 있습니다.
- 일본어 이름·음성 검색에 필요한 일본어 문자표와 내부 비교용 문자열 등은 의도적으로 유지됩니다. 재삽입을 보류한 일부 문자열도 원본 상태로 남습니다.
- 기존 세이브에 이미 저장된 사용자 입력 이름이나 일본어 이름을 일괄 변경하지 않습니다. 이름 뒤 조사와 긴 사용자 이름의 줄바꿈은 입력한 이름에 영향을 받을 수 있습니다.
- 온라인 연결 관련 5개 항목은 기존 에뮬레이터 QA에서 외부 연결 제한으로 확인하지 못했습니다. 온라인 서비스의 정상 작동을 보증하는 릴리스는 아닙니다.

최종 빌드의 실기 검증 완료 및 배포 승인은 2026-10-04 제작 의뢰자의 확인에 근거합니다. 개별 에뮬레이터 검사와 사용자 실기 승인은 구분해 기록했습니다.

문제 제보에는 패치·게임 버전, 사용 기기, 모드, 재현 순서와 화면을 적어 주세요. 설치 오류라면 `install_report.json`을 첨부하세요. 원본 게임·키·세이브는 공개 제보에 첨부하지 마세요.
