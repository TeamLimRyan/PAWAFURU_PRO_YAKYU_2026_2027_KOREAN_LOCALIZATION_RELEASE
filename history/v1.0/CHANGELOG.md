# v1.0 — 2026-10-04

- 최종 빌드 실기 검증 완료 및 제작 의뢰자 배포 승인.
- 마이라이프 이름 뒤에 중복으로 붙던 읽기 표기 수정. 일반 문구와 분리된 동적 이름 조립 경로를 함께 점검하고 수정했습니다.
- 이름 입력·생성 이름·음성 검색, 가족 기본 이름, 날짜, 메뉴와 도움말 문구 수정 반영.
- 한국 대표 선수 표기와 승인된 메뉴 이미지의 최신 수정본 반영.
- 검증된 압축 데이터를 그대로 복원하는 v0.91 설치 방식을 유지했습니다. Windows Python 3.12·3.14 전체 설치 결과가 실기 승인본과 일치합니다.
- 이전 버전 사용자도 정상적인 1.1.0 게임 원본으로 다시 설치하세요.

# v0.91 — 2026-10-03

- 같은 원본 파일로 설치해도 `만든 RES00.RDI이(가) 예상과 다릅니다. 설치에 실패했습니다.`가 뜨는 문제를 수정했습니다.
- 원인: v0.9 설치기가 PC에서 데이터를 재압축했습니다. Python 3.14의 zlib-ng와 기존 zlib가 다른 압축 바이트·배치 주소를 만들어 최종 해시가 달라졌습니다. 동일한 원본 해시로 오류를 재현했습니다.
- v0.91은 검증된 압축 데이터를 차분으로 복원하며 재압축하지 않습니다. 원본·차분·복원 본문·최종 파일의 SHA-256 검증을 유지합니다.
- 전체 데이터를 메모리에 쌓지 않고 항목별로 파일에 씁니다. 임시 폴더에서 결과를 검증한 뒤 출력에 반영하며, 일반적인 파일 교체 오류 시 기존 파일을 복구합니다.
- 실패 단계·항목·예상/실제 해시·Python 환경을 `install_report.json`에 기록합니다.
- Windows Python 3.12.10(zlib 1.3.1), 3.14.0(zlib-ng)에서 2,587개 항목 전체 설치와 출력 3파일 해시 일치를 확인했습니다. 각 환경의 오류 처리 회귀 테스트 7개도 통과했습니다.
- 게임 버전은 일본판 Base 1.0.0 + Update 1.1.0입니다. 설치 결과는 검증된 v0.9 게임 파일과 동일합니다. 이번 릴리스는 설치기 수정이며 새로운 번역·이미지 수정은 포함하지 않습니다.

# v0.9 — 2026-10-02

- 첫 GitHub 공개 배포. 일본판 Base 1.0.0 + Update 1.1.0 대상.
- 기존 한국어 텍스트·한글 글꼴 및 승인 이미지 6,957개를 반영했습니다.
- 타이틀 로고, 튜토리얼 연도 표기를 수정했습니다.
- 게임 시작 버튼의 기본 글자와 점멸 글자 위치·크기를 맞췄습니다. 정적 정렬·인코딩 검증 완료, 새 빌드의 버튼 점멸 실기 재검증은 미완료입니다.
- 선수 이름은 이름 데이터 전수 검사와 대전·기존 마이라이프 팀 명단에서 한글 표시를 확인했습니다. 다른 모드 전체와 사용자의 기존 저장 데이터는 검증 중입니다.

0.9는 전체 모드 검증 완료를 의미하지 않습니다. 알려진 한계는 KNOWN_ISSUES.md를 확인하세요.
