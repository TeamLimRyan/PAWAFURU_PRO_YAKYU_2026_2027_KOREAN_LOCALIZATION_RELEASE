# 파워풀 프로야구 2026-2027 한국어 패치 v0.91

Nintendo Switch 일본판 **Base 1.0.0 + Update 1.1.0**용 한국어 패치입니다.

**[v0.91 다운로드](https://github.com/TeamLimRyan/PAWAFURU_PRO_YAKYU_2026_2027_KOREAN_LOCALIZATION_RELEASE/releases/tag/v0.91)**

v0.9에서 같은 원본인데도 `RES00.RDI` 예상 불일치로 설치에 실패하던 문제를 수정했습니다. Python 3.12·3.14 전체 설치를 검증했습니다. ZIP 전체를 새 폴더에 풀고 [설치 안내](INSTALL_KO.md)를 따라 주세요. Source code ZIP은 설치 패키지가 아닙니다.

설치 결과의 게임 파일은 기존 검증본과 동일합니다. 이미 v0.9 설치에 성공했다면 재설치할 필요가 없습니다. 실패가 계속되면 출력 폴더의 `install_report.json`을 제보에 첨부해 주세요.

텍스트·한글 글꼴·승인 이미지 6,957개를 반영했습니다. 일부 원본 이미지의 일본어는 유지됩니다. [검증 범위](qa_summary.md), [알려진 문제](KNOWN_ISSUES.md), [변경 내역](CHANGELOG.md)를 확인하세요.
