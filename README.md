**[v1.0 다운로드](https://github.com/TeamLimRyan/PAWAFURU_PRO_YAKYU_2026_2027_KOREAN_LOCALIZATION_RELEASE/releases/tag/v1.0)**

최종 실기 검증과 제작 의뢰자 배포 승인을 반영했습니다. 이름 중복 표기·문구·메뉴 이미지 수정이 포함됩니다. 이전 v0.9·v0.91 사용자도 ZIP 전체를 새 폴더에 풀고 [설치 안내](INSTALL_KO.md)에 따라 재설치하세요. Source code ZIP은 설치 패키지가 아닙니다.
