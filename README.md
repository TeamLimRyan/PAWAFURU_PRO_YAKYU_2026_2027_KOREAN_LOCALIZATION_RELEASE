# 파워풀 프로야구 2026-2027 한국어 패치 v1.02

Nintendo Switch 일본판 **Base 1.0.0 + Update 1.1.0** 전용입니다.

**[v1.02 xdelta 다운로드](https://github.com/TeamLimRyan/PAWAFURU_PRO_YAKYU_2026_2027_KOREAN_LOCALIZATION_RELEASE/releases/tag/v1.02)**

영관나인 스카우트 전적, 고교통산 제목, 타점·도루 표기를 수정했습니다.
v1.01의 모든 수정이 포함되어 있으며, 2026-10-14 사용자 실제 화면 검증 완료와 배포 승인을 반영했습니다.

`Pawapuro2026_KO_v1.02_xdelta.zip` 전체를 풀고 [설치 안내](INSTALL_KO.md)에 따라 적용하세요.
Windows 자동 적용에는 Python이 필요하지 않습니다. Source code ZIP은 설치 패키지가 아닙니다.

이전 패치 사용자도 **수정하지 않은 1.1.0 원본에서 다시 적용**하고 RDI·RDB·IPS 세 파일을 함께 교체하세요.
NSP/XCI에 직접 적용하는 패치가 아닙니다. 기존 세이브를 삭제할 필요는 없습니다.
원본 게임·키·펌웨어·세이브는 포함하지 않습니다.
