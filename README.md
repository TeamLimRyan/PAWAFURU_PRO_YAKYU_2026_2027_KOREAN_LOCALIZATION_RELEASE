# 파워풀 프로야구 2026-2027 한국어 패치 v1.05

드래프트 경력 표시, 경기 결과의 세이브 기록, 영관 나인의 홈런 단위와 설정 설명,
각성·성장 유형 아이템 팝업, 일반·고속 경기의 몸에 맞는 공 이미지를 수정했습니다.
이전 패치의 전체 내용을 포함합니다.

Nintendo Switch 일본판 **Base 1.0.0 + Update 1.1.0** 전용입니다.
`Pawapuro2026_KO_v1.05_xdelta.zip` 전체를 받아 새 폴더에 풀고 [설치 안내](INSTALL_KO.md)를 따라 주세요.
수정하지 않은 원본에서 새로 적용한 RDI·RDB·IPS 세 파일을 함께 교체하세요.
이전 한국어 모드는 모드 경로 밖에 백업하고 새 버전 하나만 활성화하세요. 기존 세이브는 삭제하지 마세요.
이전 패치를 순서대로 적용할 필요가 없습니다. GitHub의 Source code ZIP은 설치 파일이 아닙니다.
Windows 자동 적용에는 Python이 필요하지 않습니다.

이번 제보 7유형의 대상 화면 26건, 원본 복원·설치·파일 해시 검사를 통과했습니다.
일부 화면은 격리된 QA 데이터와 원래 연출 호출로 검증했습니다. 검증 방법과 제한은 [QA 요약](qa_summary.md)을 참고하세요.
기존 투수 교체 설명의 일본어 잔존 제보는 계속 조사 중입니다.
