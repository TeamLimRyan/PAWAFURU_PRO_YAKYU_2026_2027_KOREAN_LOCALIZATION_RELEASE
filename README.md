# 파워풀 프로야구 2026-2027 한국어 패치 v1.04

[v1.04 다운로드](https://github.com/TeamLimRyan/PAWAFURU_PRO_YAKYU_2026_2027_KOREAN_LOCALIZATION_RELEASE/releases/tag/v1.04)

홈런 연출을 굵고 촘촘한 한글 글씨체와 넓은 금색 입체면으로 새로 제작했습니다.
어레인지 기본 팀 제목, 홈런 배틀 로고와 선택지 표현을 수정하고, 설정·도움말 참조 및 설치 검사를 보강했습니다.
이전 패치의 전체 내용을 포함합니다.

일본판 Base 1.0.0 + Update 1.1.0 전용입니다. `Pawapuro2026_KO_v1.04_xdelta.zip` 전체를 풀고
[설치 안내](INSTALL_KO.md)에 따라 수정하지 않은 원본에서 적용하세요. RDI·RDB·IPS 세 파일을 함께 교체하고
이전 한국어 모드는 모드 경로 밖에 백업한 뒤 새 버전 하나만 활성화하세요. 기존 세이브는 삭제하지 마세요.
이전 패치를 순서대로 적용할 필요가 없습니다. Source code ZIP은 설치 패키지가 아닙니다.
Windows 자동 적용에는 Python이 필요하지 않습니다.

한글 15자와 숫자 2·3의 모델 17개, 31종 연결·배치 검사와 대표 6종 실제 게임 녹화 검수를 마쳤습니다.
원본 복원·전체 설치·파일 해시 검사도 통과했습니다. 설정·도움말 제보자의 실제 설치 원인은 미확인이고,
기존 투수 교체 설명 일본어 제보는 미해결입니다.
